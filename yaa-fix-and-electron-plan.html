11Migration system

database/db.js:34 — createTables()

Đây là rủi ro lớn nhất với người dùng lâu dài. Không có version tracking, mọi thay đổi schema đều là thay đổi phá vỡ. Dùng PRAGMA user_version của SQLite — không cần thư viện.

async migrate() {
  const row = await this.getRow('PRAGMA user_version');
  let v = row?.user_version ?? 0;

  const migrations = [
    /* v1 */ async () => { await this.createTables(); },
    /* v2 */ async () => {
      await this.executeQuery('ALTER TABLE productions ADD COLUMN foo TEXT');
    },
  ];

  for (; v < migrations.length; v++) {
    this.logger.info(`Migrating DB v${v} → v${v + 1}`);
    await migrations[v]();
    await this.executeQuery(`PRAGMA user_version = ${v + 1}`);
  }
}

Gọi migrate() thay cho createTables() trong initialize(). Từ đó về sau mỗi thay đổi schema là thêm một hàm vào mảng.

12Bọc transaction cho luồng approve

index.js:818–828 — approveContent()

saveContentReview() → updateProductionStatus() → notify() đang là ba lệnh rời. Máy sleep, process bị kill, hoặc lỗi giữa chừng là state lệch: review ghi approved nhưng production vẫn pending, hoặc ngược lại.

// thêm helper trong db.js
async transaction(fn) {
  await this.executeQuery('BEGIN');
  try {
    const result = await fn();
    await this.executeQuery('COMMIT');
    return result;
  } catch (e) {
    await this.executeQuery('ROLLBACK');
    throw e;
  }
}
Với better-sqlite3 (E1) việc này còn đơn giản hơn — nó có db.transaction(fn) sẵn và chạy đồng bộ.

13Graceful shutdown

index.js — cuối file, sau start()

Hiện db.close() không bao giờ được gọi. Ctrl+C hoặc đóng app là cắt ngang job đang chạy, SQLite có thể để lại -journal. Với Electron thì bắt buộc phải có, vì before-quit cần chờ backend dọn xong.

async shutdown() {
  this.logger.info('Shutting down...');
  if (this.scheduler) await this.scheduler.pauseAutomation();
  if (this.server) await new Promise(r => this.server.close(r));
  if (this.db) await this.db.close();
}

// và ở cuối file
for (const sig of ['SIGINT', 'SIGTERM']) {
  process.on(sig, async () => { await agent.shutdown(); process.exit(0); });
}

Nhớ gán this.server = this.app.listen(...) ở mục 01 để có handle mà close.

Bug thật phát hiện khi test bản Electron đã đóng gói: server.close(cb) chỉ gọi cb sau khi mọi connection tự đóng — mà dashboard poll /api/dashboard mỗi 8 giây qua keep-alive connection thì không bao giờ tự đóng. Kết quả: shutdown() treo vô hạn, app không bao giờ thoát thật sự dù log đã in "Shutting down...". Sửa bằng this.server.closeAllConnections() (Node ≥18.2) trước khi await callback. Đã verify: treo vô hạn → còn ~2ms.

E1Đổi sqlite3 → better-sqlite3

sqlite3 là native module cần node-gyp rebuild theo ABI của Electron — phiền và hay hỏng. better-sqlite3 có prebuilt sẵn cho Electron, API đồng bộ (đơn giản hơn), có transaction() built-in, và giải quyết luôn nhánh CVE critical từ node-gyp/tar ở mục 10.

npm uninstall sqlite3
npm install better-sqlite3

Sửa ba helper ở database/db.js:912–946 — chúng đang bọc callback thành Promise, giờ chỉ cần gọi thẳng:

executeQuery(q, p = []) { const r = this.db.prepare(q).run(...p);
                          return { lastID: r.lastInsertRowid, changes: r.changes }; }
getRow(q, p = [])       { return this.db.prepare(q).get(...p); }
getAllRows(q, p = [])   { return this.db.prepare(q).all(...p) || []; }

Các caller đang await vẫn chạy bình thường (await giá trị không phải Promise là hợp lệ), nên không phải sửa lan ra. Riêng db.exec() dùng cho DDL nhiều câu.

E2Trừu tượng hoá đường dẫn data / config

Đây là phần chiếm nhiều công sức nhất. db.js, credential-manager.js và các agent đều dùng path.join(__dirname, '..', 'data' | 'config'). Trong app đã đóng gói, thư mục đó nằm trong app.asar — read-only, ghi vào là crash. Phải chuyển hết sang app.getPath('userData').

// utils/paths.js — file mới
const path = require('path');

function root() {

  } catch (_) { /* chạy ngoài Electron */ }

}

const ROOT = root();

  ROOT,

E7Luồng OAuth trong app

oauth-server.js, modern-auth.js

Giữ nguyên oauth-server.js nghe localhost:8080 — Google cho phép redirect URI http://localhost với OAuth client loại Desktop app, không cần HTTPS hay domain.

  • Mở URL authorize bằng shell.openExternal(), không bằng BrowserWindow
  • Google chặn embedded webview cho OAuth — làm trong BrowserWindow sẽ bị từ chối đăng nhập
  • oauth-server.js:96 đang spawn('node', ['index.js']) sau khi auth xong — bỏ đoạn này trong Electron, backend đã chạy sẵn
  • Thay walkthrough.js (inquirer CLI) bằng UI setup trong dashboard, hoặc giữ tạm và chạy ngoài terminal lần đầu
Chưa làm. Chưa test được vì chưa có credential thật để đi hết luồng OAuth trong app đóng gói — cần làm khi có API key/OAuth client thật để verify shell.openExternal() + callback vào localhost:8080 hoạt động đúng.

Chỉ cần nếu sau này chuyển sang VPS

Với bối cảnh local hoặc desktop app, những mục này bỏ qua được. Ghi lại phòng khi bạn đổi hướng.

  • Auth cho toàn bộ /api/* — hiện requireAPIKey() chỉ gắn vào route mutating. Mọi GET đều mở: /api/dashboard lộ settings và profile, /api/content/:id lộ script đầy đủ, /api/content/:id/asset/* cho tải thẳng video.
  • crypto.timingSafeEqual thay cho !== khi so sánh API key (index.js:165).
  • Reverse proxy + TLS — Caddy với basic_auth phủ toàn bộ /; app vẫn bind 127.0.0.1, proxy mới là thứ nghe public.
  • Rate limit trên /generate — mỗi request là tiền API thật.
  • Firewall chỉ mở 22 và 443.
  • Cách gọn hơn: không expose gì cả — SSH tunnel hoặc Tailscale. OAuth callback chỉ chạy một lần, sau đó googleapis tự refresh qua outbound HTTPS, không cần inbound.
